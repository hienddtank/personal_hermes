---\nname: Local File Access\ndescription: Access and manipulate files/folders on local drives (C:, D:, E:, F:, G:)\nversion: 1.1\nauthor: Hermes Agent\n---\n\n# Local File Access Skill\n\nThis skill provides tools to access and manipulate files and folders on your local Windows computer, extending beyond the container filesystem to all available drives (C:, D:, E:, F:, G: etc.).\n\n> **⚠️ IMPORTANT: Not all drives are auto-available.**\n> Inside the Hermes container, only D: and E: are automatically mounted by Docker Desktop's 9P server (at `/host/d/` and `/host/e/`). Drives F:, G:, etc. must be **explicitly added** to `/opt/hermes-agent/docker-compose.yml` as bind mounts before they appear inside the container. See the main [`windows-exec-from-container`](../SKILL.md) skill for instructions.\n\n## Available Commands\n\n### List All Drives\n```bash\nwmic logicaldisk get name,freespace,caption\n```\nShows all available drives and their free space.\n\n### List Folder Contents (D: Drive)\n```bash\ndir \"D:\\Path\\To\\Folder\" /b /o-d\n```\nLists files in a folder (reverse chronological order).\n\n### Create Directory on Any Drive\n```bash\nmkdir \"E:\\NewFolder\"\nmkdir \"F:\\AnotherFolder\"\n```\n\n### Copy Files/Folders Between Drives\n```bash\ncopy \"C:\\Source\\File.txt\" \"D:\\Destination\\\"\n# or for folders\nxcopy \"C:\\Source\\Folder\" \"D:\\Destination\\Copy\" /s /e\n```\n\n### Move/Rename Files Across Drives\n```bash\nmove \"E:\\OldName.txt\" \"F:\\NewName.txt\"\n```\n\n### Delete Files/Folders\n```bash\ndel \"G:\\FileToDelete.txt\"\n# or for folders (with confirmation)\nrmdir /s /q \"H:\\EmptyFolder\"\n```\n\n### Search Files Recursively\n```bash\ndir D:\\ /s /b | findstr /i \"filename\"\n```\n\n### Check File Details\n```bash\ndir \"D:\\File.txt\"\n```\n\n## Common Operations\n\n### Access Different Drives\n- **C:** Windows system drive (usually)\n- **D:, E:, F:, G:** Data drives, external disks, or mounted volumes\n\n### Path Formats\n- Use `D:\\` for Windows paths\n- Use `/b` for bare filenames (no headers)\n- Use `/s` to search subdirectories\n- Use `/o-d` to sort by date descending\n\n## Examples\n\n### List all files on D: drive\n```bash\ndir \"D:\\\" /b /o-d\n```\n\n### Copy a folder from C: to E:\n```bash\nxcopy \"C:\\Users\\Documents\" \"E:\\Backup\\\" /s /e /y\n```\n\n### Search for specific file across drives\n```bash\npowershell -Command \"Get-ChildItem D:\\,E:\\,F:\\ -Recurse -Filter *.txt | Select-Object FullName\"\n```\n\n### Create a new folder on F: drive\n```bash\nmkdir \"F:\\NewProject\"\ncd \"F:\\NewProject\"\n```\n\n## Troubleshooting\n\n**\"Access is denied\"** - Run the command prompt as administrator or check permissions.\n\n**\"The system cannot find the file specified\"** - Verify the path and drive letter. The container may not have direct access to Windows paths. Try:\n- Using the full container path: `/host/d/...` instead of `D:\\...`\n- Checking if the drive is mounted in Windows Disk Management\n\n**When read_file fails with Windows paths**: Use Python's csv module directly via execute_code, as the shell may not properly handle Windows path formatting. Example:\n```python\nimport csv\nfile_path = \"/host/d/mkt/python/B2B cleaning 2/Agency Database - Nhung.csv\"\nwith open(file_path, 'r', encoding='utf-8') as f:\n    reader = csv.reader(f)\n    rows = list(reader)\n```\n\n**Drive not accessible** - Check if the drive is mounted in Windows Disk Management.\n\n### Reading Files from Mounted Drives (Windows → Container Mapping)\n\nWindows drives are mounted at `/host/<letter_lowercase>/` in the container:\n- D: → `/host/d/` (auto-mounted by Docker Desktop 9P)\n- E: → `/host/e/` (auto-mounted by Docker Desktop 9P)\n- F: → `/host/f/` (requires explicit docker-compose.yml bind mount — see `windows-exec-from-container` skill)\n\n**Quick verification before reading:**\n```bash\nfile /host/d/filename.xlsx   # Check file type first (expect \"Microsoft Excel 2007+\")\npip install openpyxl --quiet  # Install if needed\n```\n\n**Reading Excel with Python when read_file fails on Windows paths:**\n```python\nimport csv, os\nfor f in sorted(os.listdir('/host/d/')):\n    full = f'/host/d/{f}'\n    print(f'{f} ({os.path.getsize(full)} bytes)')\n```\n\n### Troubleshooting Path Issues\n- Use `/host/d/...` for mounted drive access (not `D:\\\\...`)\n- Verify mounts in Windows Disk Management before assuming paths exist\n- Use `file <path>` to confirm file format before reading attempts\n\n### Massive Directories: `search_files` Times Out, Use Terminal `find` Instead\nWhen scanning directories with **thousands of files** (e.g., B2B data folders with 100k+ CSV/XLSX files), the `search_files` tool will timeout. Use terminal commands instead:\n\n```bash\n# List all CSV/Excel files with row counts, sorted largest first\nfind /host/d/mkt/python/B2B -iname '*.csv' -o -iname '*.xlsx' | while read f; do rows=$(($(wc -l < \"$f\") - 1)); echo \"$rows|$f\"; done | sort -t'|' -k1 -rn\n\n# List all files in a directory (bare format, no search)\nls /host/d/mkt/python/B2B/*.csv 2>/dev/null\n\n# Find large directories consuming space\ndu -sh /host/d/mkt/python/B2B/*/ | sort -rh | head -20\n```\n\n## Adding a New Drive\n\nDrives beyond D: and E: require a bind mount in docker-compose.yml. See **Method 3** in the parent skill (`windows-exec-from-container`) for full instructions.\n\n### Quick Reference\n```yaml\n# In /opt/hermes-agent/docker-compose.yml, add to both gateway and dashboard services:\nvolumes:\n  - ~/.hermes:/opt/data\n  - F:\\:/host/f:rw   # Add drive F:\ at /host/f/\n```\nAfter editing, restart: `docker compose down --remove-orphans && docker compose up -d --force-recreate`
