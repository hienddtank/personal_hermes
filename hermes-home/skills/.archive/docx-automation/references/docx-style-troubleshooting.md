# python-docx Style Troubleshooting

## ⚠️ CRITICAL: Changing a Paragraph's Style

**This does NOT work:**
```python
p.paragraph_format.style = doc.styles['List Bullet']  # SILENTLY FAILS
```

**Correct approaches (in order of preference):**
1. **Pass style when creating:** `doc.add_paragraph(text, style='List Bullet')`
2. **Direct assignment:** `p.style = doc.styles['List Bullet']`

**Style inheritance trap:** After `doc.add_heading(...)`, subsequent plain `doc.add_paragraph()` calls may inherit Title or unexpected styles. Always specify `style=` explicitly for normal paragraphs.

## Common Issue: Missing 'List Bullet' Style

When loading a .docx file, the `doc.styles['List Bullet']` lookup can fail with:
```
KeyError: "no style with name 'List Bullet'"
```

### Why
Not all .docx files are created with the standard bullet list styles. A document might:
- Be created in Word but use custom numbering instead of styles
- Have been generated by a tool that strips styles
- Use paragraph formatting (manual bullets) instead of style-based bullets

### Diagnosis
```python
available = [s.name for s in doc.styles]
# Check what's actually available — you might see:
# ['Normal', 'Heading 1', 'List Paragraph', 'Quote', ...]
```

### Fix — Manual Bullets (Most Reliable)
Instead of relying on a style, inject the bullet character directly:
```python
def add_bullet(text):
    p = doc.add_paragraph()
    p.text = ''
    run = p.add_run('\u2022 ' + text)  # Unicode BULLET (U+2022)
    return p
```

### Fix — Use 'List Paragraph' Instead
Some documents have `'List Paragraph'` but not `'List Bullet'`. This applies bullet formatting if the document's base template defines it:
```python
try:
    style = doc.styles['List Paragraph']
except KeyError:
    # Fall back to manual
    pass
```

## Timeout Issues

python-docx operations can hang silently on corrupted or very large documents.

### Debug Pattern
Add print statements between each major operation:
```python
print("1: imported")
doc = docx.Document(path)
print("2: loaded")
doc.add_heading('Test', level=1)
print("3: heading added")
doc.save(output_path)
print("4: saved")
```

Run with `timeout 30` to detect hangs immediately.
